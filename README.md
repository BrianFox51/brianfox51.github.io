# Mythic Mask Works

A cinematic visual biography made with HTML, CSS, and plain JavaScript. There are no build tools or framework dependencies.

## Preview

Open `index.html` in a browser, or open this folder in VS Code and use a local preview extension.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Add the contents of this folder to the repository's root directory.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and the root folder, and save.

The site uses a locally stored background image in `assets/`, so it travels with the page when you publish it. The background was generated for this site. Motion respects the visitor's reduced-motion preference.

The two leadership cards near the bottom introduce the Managing Member/CFO and Creative Director. The CFO profile links to `https://mythicmaskworks.com/metchelyn-baker/`; publish Mrs. Baker's profile at that path for the link to resolve. The Creative Director card links to the story section on this page. The card images are labeled accordingly.

## Personalize

- Replace the three "Follow the work"/contact destinations with your actual portfolio or social links when you have them.
- Update the biography in `index.html` with any specific projects, dates, or institution details you want to include.
